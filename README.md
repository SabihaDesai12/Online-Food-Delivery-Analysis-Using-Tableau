# Online Food Delivery Analysis Using Tableau

## Project Overview
This project analyzes online food delivery data using Tableau. It focuses on customer preferences, ordering behaviour, ratings, reviews and food ordering trends.

## Objectives
- Analyze online food delivery data.
- Understand customer food preferences.
- Study customer ordering behaviour.
- Analyze ratings and reviews.
- Create interactive dashboards and visualizations.

## Tools & Technologies
- Tableau Public
- Microsoft Excel
- CSV Dataset
